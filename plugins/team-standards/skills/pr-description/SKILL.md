# Team PR description

Compare the current branch with `main` and produce:

## What
One or two sentences on what changed.

## Why
The problem or ticket this solves.

## How to test
Numbered steps a reviewer can follow.

## Checklist
- [ ] Tests added or updated
- [ ] No secrets or debug logs
- [ ] Screenshots attached for UI changes
